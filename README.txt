HOW TO RUN
1. Unzip, open the folder in VS Code, right-click index.html > "Open with Live Server".
   (Needs internet for Three.js and Google Fonts.)
2. Photo: replace assets/photo.jpg with your picture (keep the same name). Portrait 3:4 works best.
3. Resume button: put your PDF at assets/Ayush_Ojha_Resume.pdf.
4. Links: in index.html, search for data-todo and replace href="#" with your GitHub, LinkedIn,
   Varma Alankar, landing page and Question Paper Generator URLs.

LOGOS: put PNGs in assets/logos/ named varma-alankar.png, shree-jewellers.png, shree-ganesh.png, new-manikanchan.png, sandhya-enterprise.png (a letter badge shows until a logo exists).

More logos: ecstacy-salon.png, padmavati-jewellers.png, deepak-garments.png, approch.png in assets/logos/.
If a project site is offline, add class off to its card: class="card tilt off" (hides the link, shows 'not live now').
